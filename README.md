## Contents

* `ff/`: force-field parameters (CHARMM36m, GROMACS `.itp` format)
* `pdb/`: structure files for lysozyme and for each solution component
* `mdp/`: molecular dynamics parameter files (GROMACS `.mdp`)
* `system_example/`: example workflow for one initial configuration of one system
